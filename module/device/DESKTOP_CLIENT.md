# Windows 桌面客户端适配

本功能源自 [LGG686 的 PR #6](https://github.com/xylolit-mu/OnmyojiAutoScript/pull/6)，
上游版本 `d316b7a0b7393b00b80e51d293faa22f28062bdd`。
本地按该 PR 相对 `bbb7f1d085b3738e4c043be030ce1a8602117002` 的最终差异接入，
保留目标分支现有 MuMu、多任务调度、协斗与棋局拖拽增强，不重复导入公开库的其他历史。

## 配置

- `script.desktop.enable`：启用桌面模式，默认关闭。
- `game_path`：客户端安装目录；留空尝试自动发现。
- `profile_dir`：账号档案目录。多开时每个配置必须使用不同目录，且与安装目录分离。
- `window_pos` / `window_title`：窗口位置与显示标题。
- `launch_instance`：一次性启动按钮，提交后台任务后立即复位。
- `restart_when_window_exists`：是否在窗口仍存在时强制重启，默认关闭。

桌面模式不走 ADB，使用客户区后台截图和窗口消息输入。
识别空间统一为 1280×720，窗口消息坐标按实际客户区与 DPI 换算。
遮挡与最小化不同：截图前会尝试还原最小化窗口，不支持把零尺寸客户区当作正常画面。

启动状态可查询后端路由 `GET /{配置名}/desktop/launch-status`。
状态为 `idle`、`queued`、`running`、`succeeded`、`failed`，失败原因同时记录日志。

## 相对上游的修复

1. 认领窗口前检查 PID、进程创建时间和程序目录；关闭进程在同一进程句柄上复核创建时间。
2. 同一安装目录的 UI 按钮和 worker 启动操作加跨进程锁，锁内重新检查已有实例。
3. 拒绝不同配置共用账号档案，以及档案目录与安装目录重叠。
4. 多开 Job 归属失败或成员暂为空时不退回宽松窗口绑定；状态文件使用独立临时文件原子替换。
5. 启动按钮异步执行并提供状态查询，不在配置接口中等待最多 90 秒。
6. 后台截图正常与异常路径均释放位图、兼容 DC 和窗口 DC。
7. ROI 容差按设备在每个识别请求中设置并复位，不修改全局默认；不扩大亮度统计采样范围。

## 验证与限制

`module.device.check_desktop` 使用模拟窗口/进程和临时目录验证关键分支，
不会启动、停止或操作真实客户端。与原有拖拽、Frame、网络恢复、协斗和调度检查一起运行。

本次接入未进行桌面客户端实机验收。启用前应验证实际客户端版本、双账号并发、
100%/125%/150% DPI、跨屏、最小化恢复、登录掉线及按住拖拽。
上游“复制少量配置 + 共享资源目录 + 独立 USERPROFILE”的账号隔离仍依赖客户端实际存储行为，
不能仅凭单元测试断言所有客户端版本都隔离成功。

PR 作者提及的协斗大轮奖励弹窗问题不包含在该 PR 的改动中，未随桌面适配自动修复。
